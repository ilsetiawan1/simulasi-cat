# my-agent-template

> Starter template and standardized rules for AI agent workflows: FigCraft UI/UX design and Full-Stack engineering (Feature-Driven Architecture & Repository Pattern).

---

## Isi Repositori

* **`AGENTS.md`**: Dokumen pedoman utama AI Agent terpadu dengan seleksi mode otomatis:
  * **Bagian A (Fase Desain):** Integrasi `antislop-ui`, `antislop-layoutmobile`, `antislop-copywriting`, tipografi logo ter-highlight, bebas pill-soup, dan live generation di FigCraft.
  * **Bagian B (Fase Koding):** Frontend Feature-Driven Architecture (FDA), Backend Repository Pattern, prinsip anti-overengineering `ponytail`, audit keamanan `security-audit`, dan kebijakan **Zero RegEx**.
  * **Bagian C (Protokol Transisi):** Konversi otomatis layout FigCraft menjadi struktur kode modular.
* **`docs/PRD-template.md`**: Template dokumen kebutuhan produk (*Product Requirements Document*) berbasis MoSCoW, user journey, dan NFR di dalam folder `docs/`.
* **`docs/TSD-template.md`**: Template spesifikasi teknis (*Technical Specifications Document*) berbasis arsitektur FDA, Repository Pattern, skema entitas database, dan batasan koding di dalam folder `docs/`.

---

## Cara Menggunakan Template Ini

1. **Jadikan Template di GitHub:**
   * Di repository GitHub Anda (`my-agent-template`), buka **Settings** $\rightarrow$ centang **"Template repository"**.
2. **Saat Membuat Project Baru:**
   * Klik tombol hijau **"Use this template"** $\rightarrow$ **"Create a new repository"**.
3. **Isi PRD & TSD:**
   * Di dalam folder `docs/`, ubah nama `PRD-template.md` menjadi `PRD.md` dan `TSD-template.md` menjadi `TSD.md`, lalu isi kebutuhan spesifik project Anda.
4. **Instruksi Inisialisasi ke AI Agent:**
   * Di jendela chat Antigravity, cukup beri perintah:
     > *"Tolong baca docs/PRD.md dan docs/TSD.md, lalu sesuaikan AGENTS.md untuk project ini."*
   * Agent akan secara mandiri menganalisis kebutuhan Anda dan memperbarui metadata proyek, daftar fitur FDA, serta skema database pada `AGENTS.md`.
